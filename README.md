# EL Cultivo — Premium Website

## Publish on GitHub Pages
1. Extract this ZIP.
2. Open your GitHub repository and upload/replace the files in the repository root.
3. Keep `index.html`, `el-cultivo-logo.png`, and all `image-*.jpg` files together in the same folder.
4. Commit the changes. GitHub Pages will publish the updated site.

The enquiry form opens WhatsApp with the visitor's details pre-filled. It does not store submissions in a database.
