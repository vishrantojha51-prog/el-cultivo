EL Cultivo Premium Interactions Patch

This optional patch adds:
- Gentle scroll reveal animations for public-page sections and cards.
- Matching reveal behavior for product/project cards loaded later from Supabase.
- Subtle hover/focus feedback for service, product, and gallery cards.
- An accessible Back to Top control.
- Reduced-motion support and mobile-specific motion adjustments.

It does not modify admin.html, Supabase configuration, database logic, contact form logic, existing images, or video.

Upload/replace these five root HTML files:
index.html
about.html
solutions.html
projects.html
contact.html

Add these two new files inside assets/:
premium-interactions.css
premium-interactions.js

Keep all existing files. Do not upload the backup folder or replace admin.html.
